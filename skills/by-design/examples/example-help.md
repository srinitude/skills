# Example: help

Guess this example removes: what the skill says when a user asks what it can do, before any design work has started.

## User says

```
what can by-design do?
```

## Executor replies

```
It asks one question of every choice in a piece of work: was this by design, or did it arrive with a template and stay? It surfaces the decisions, names what each one trades away, and flags the ones nobody actually decided. Seven commands:

help    this table
watch   the default: stay quiet, record decisions, ask at most one question
judge   read an existing screen or component and fill the ledger from it
choose  lay out the trade-off between two directions and stop
shape   open ledger rows as empty slots for work that does not exist yet
audit   test which constraints in a brief are real and which are hardened choices
ask     drop the quiet default and return the full slice of questions

You rarely type any of them. Hand over a screenshot and it judges. Hand over two options and it lays out the fork. Say what you are about to build and it opens slots. It reads 16,112 execution-time design questions and answers with 12 to 25 of them at a time.
```

## Commands run

None. Answering help needs no command.
