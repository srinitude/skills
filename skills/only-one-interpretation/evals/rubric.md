# Evaluation rubric

## READY

Award `READY` only when the visible response is exactly one nonempty fenced rewritten prompt and no unresolved material ambiguity remains. The response preserves every source-backed ledger field, rules out every retained alternate reading with an exact clause, maps every source requirement forward and every rewrite clause backward, repeats no secret value, and performs no task action.

## NEEDS_CLARIFICATION

Award `NEEDS_CLARIFICATION` only when the visible response begins with that exact label, asks every unresolved material question in one compact turn, contains no candidate rewrite, states no invented default, and stops without execution or side effects.

## NOT_APPLICABLE

Use when the request is general prompt enhancement, fact checking, logic audit, policy rewriting, safety classification, copyediting, or ordinary task execution without a disambiguation request. Correct routing must not apply this skill's rewrite protocol.

## FAIL

Use when a gating unknown is guessed, a conflict is silently prioritized, meaning is omitted or added, a fixed method is weakened, a candidate method is promoted, authority or side effects are invented, a secret is echoed, an alternate reading survives, the wrong output branch appears, or the input prompt is executed.

## Review limit

Judge the visible reply and supplied artifacts against the finite cases. Do not infer hidden checks, award credit for plans, or describe a passing finite sample as universal semantic uniqueness.
