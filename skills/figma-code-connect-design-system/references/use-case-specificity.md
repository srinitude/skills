# Figma and Code Connect use case

Load this note through `mise run domain-research-policy` before changing Figma terms, owners, states, mappings, or proof.

## Outcome

This skill joins one real Figma design system to real TypeScript React APIs through Code Connect. It keeps Figma pages, nodes, props, code exports, rendered states, rights, and visual proof distinct. A valid file or mapping is not a visual or product PASS.

## Evidence

Use [Figma React Code Connect](https://developers.figma.com/docs/code-connect/react/) through `mise run domain-research-policy` for string, boolean, enum, instance, children, slot, and nested prop behavior. Use [Figma component property types](https://developers.figma.com/docs/plugins/api/ComponentPropertyType/) through the same task for native property kinds. Use [Figma template files](https://developers.figma.com/docs/code-connect/template-files/) through the same task for parserless templates and nested output. Use [Figma file nodes](https://developers.figma.com/docs/rest-api/files/) through the same task for page and node ancestry. These sources set contracts. They do not prove a product need, correct visual use, code parity, or current delivery.

## Domain map

Map actors, files, pages, nodes, layers, components, properties, variants, APIs, mappings, rights, failures, repairs, proof, time, resources, quality, terms, and exclusions. Each retained design property needs a product reason. Each property also needs exact Figma and TypeScript React API proof, or a proved not-applicable record.

The same sight owner must inspect current rendered pixels. Fixed checks can reject missing pages, stale IDs, bad types, fake props, broken links, or wrong ancestry. They cannot grant good design, clean canvas, correct attention, or product fit.

## Boundaries

Mise owns repeatable inventory, schemas, task order, receipts, hashes, parity shape, invalidation, and package checks. The model owns source meaning, product need, visual judgment, experiments, and direct sight. People own product intent and high-impact mutation rights. Figma readback owns current node facts. The repository owns current code facts. Code Connect owns its current mapping output. One owner cannot stand in for another.

This skill can run alone. Project boards, videos, transcripts, private inspiration, and product runtime data may serve as outside evidence in a project run. They do not become portable skill dependencies.
