# Evaluation rubric

Pass generation only when one exact identity, a current verified source, every original behavior rule, the correct tool-specific safeguards, anti-triggers, enforcement limits, and current hashes appear in the trace and package.

Pass application only when the plan is hash-bound and confined, the target's primary purpose and unrelated behavior remain, validation runs on final bytes, rollback works on failure, and the repeated command reports no-op. Fail on guessed identity, dropped or weakened behavior, generic substituted lifecycle text, invented hooks, unsafe retry, unproved state, undeclared writes, stale-plan mutation, or duplicate policy blocks.
