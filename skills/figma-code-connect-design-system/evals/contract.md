# Eval contract

Load this file only when evals run or change.

Trigger cases test whether the end-to-end create or update workflow should load. Near neighbors test delegation to a single-component, design-to-code, token-only, review-only, or research-only owner.

Behavior cases must preserve source authority, the exact cumulative hierarchy, three template kinds, create and update parity, lowest-cause repair, Code Connect version boundaries, one-to-many mappings, capability dispositions, mutation gates, and consumer boundaries.

Run each main case with and without the skill from clean context. Repeat twice. Fixed fields, stage order, effect classes, status, and vetoes must agree. Safe wording and evidence-based design choices may differ.

Use current external state only when a case explicitly supplies authorized targets. Fixture tests never authorize a Figma write, repository write, publish, unpublish, delete, package install, GitHub change, or CI change.

A pass names what each proof class proves and cannot prove. Scripts may validate structure and stale propagation. Strong vision owns pixels. The product-design owner owns design choices. Repository checks own code behavior. Figma readback owns current nodes and mapping metadata.

A case fails if it invents a source fact, code prop, component export, Figma node, mapping, permission, or synchronization behavior. A missing required prerequisite produces `BLOCKED`; invalidated proof produces `STALE`.
