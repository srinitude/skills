# skill-factory decisions

Load this file and `assets/decision-records.json` through `mise run decision-policy` when a current factory choice needs its reason. This file keeps the short human history.

- 2026-09-02: reject generic scaffold clauses in use-case primitives, decision records, and invocation receipts because domain labels alone cannot prove that an agent skill action advances its promised outcome.
- 2026-09-02: required every domain aspect, package primitive, and Mise task to state how it advances an agent skill outcome because generic package shape can pass while real task value remains absent.
- 2026-09-02: required every support-file disclosure to name its owning Mise task because a bare path can bypass the checked agent skill operation or load context without a job.
- 2026-09-02: made model capability preservation a hard acceptance boundary because deterministic agent skill scaffolding has failed if it disables the perception, research, tools, reasoning, or creativity the outcome needs.
- 2026-09-02: deferred latest-stable Mise maintenance until agent skill outcome work concludes because a mid-run runner replacement can invalidate active evidence and plugin updates would broaden the change.
- 2026-09-02: bound the Mise primitive catalog to the self-updated release schema because upstream primitives must be reconciled without silently rewriting agent skill decisions.
- 2026-09-02: required complete aspect and primitive lifecycles because agent skill creation without task-owned inspection, change, proof, recovery, deprecation, and retirement is incomplete.
- 2026-09-02: required one acyclic dependency path from each public operation because cycles, diamonds, and redundant routes make task ownership and acceptance uncertain.
- 2026-09-02: required an invocation receipt that runs or justifies every task because silent omission can hide applicable agent skill work.
- 2026-09-02: made the factory obey its own generated-skill contract because an exempt factory can reproduce its own drift in every output.
- 2026-09-02: removed destructive scaffold replacement because creating a new agent skill never authorizes erasing an existing directory.
- 2026-09-02: made collisions, symlinks, and unknown host owners fail migration planning because an exit-zero warning can leak external bytes or permit an ambiguous write.
