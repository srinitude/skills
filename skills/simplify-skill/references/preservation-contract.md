# Preservation contract

Resource gate: run `mise run validate` before using package files named here.

Parent and backlink: [`../SKILL.md`](../SKILL.md), Procedure steps 2, 3, and 8.

Freeze an ordered baseline packet of every governed file, origin fact, existing check, and representative task. Record path, bytes, hash, and absent files.

Assign source IDs in order. Every ledger row records exact text, normalized meaning, authority, requirement strength, conditions, exceptions, observable behavior, protected-span status, action, target, evidence, and review state.

Allowed actions are `keep`, `deduplicate`, `clarify`, `reorder`, `move`, `extract`, and `approved_drop`. Coverage must equal `1.0`. `approved_drop` needs an exact approval record and loss bound.

Protected spans include commands, flags, paths, schemas, hashes, quotations, legal text, IDs, version ranges, permission rules, and numeric limits. They must remain byte equal or carry exact approval.

Veto acceptance when a rule, condition, exception, state, output, proof path, safety boundary, permission, rollback, or stop behavior regresses; a dependency is invented; no declared cost falls; or a child lacks ownership and direct proof.

Use `ACCEPT`, `NO_CHANGE`, `NEEDS_APPROVAL`, and `BLOCKED` only. Machine decisions use canonical sorted JSON and closed values. Free prose may explain a branch but cannot select it.
