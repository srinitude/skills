# Evaluation rubric

- This file sets what passes or fails a case.

## Judge each run

### Pass

- The rewrite keeps the source meaning and exact data.
- The reading paths stay sound.
- Every claimed check has real output behind it.

### Fail

- The meaning changed, or exact data was lost or altered.
- The rewrite invents facts.
- A required check is reported as passed without output.
- Any veto in the case appears.
