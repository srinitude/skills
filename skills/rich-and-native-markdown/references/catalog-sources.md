# Catalog sources

- Read this file to check a source key, the research date, or a version limit.

## Reading this file

- Prerequisites: the supplied text and its target format; no other catalog file is a required read.

### Terms and syntax

- A dialect is a syntax rule set; a renderer makes its view. A parser reads the syntax.
- Related entry IDs are labels, not required reading links. Check any real content dependency before using it.

## Research dates and limits

- All sources were accessed on 2026-09-17.
- CommonMark's current published version is 0.31.2 (2024-01-28); GFM's published specification is 0.29-gfm (2019-04-06).
- These older sources remain because they own the syntax.
- The inspected Pandoc guide is dated 2026-08-28.
- MultiMarkdown 7's README identifies 7.0.0-beta.2 on 2026-07-29; its guide is revised 2026-03-13 and has unfinished sections.
- The MMD6 forms in this catalog are explicitly historical, not verified MMD7 behavior.
- Other living owner pages do not all state publication dates; never substitute their crawl date.
- This is a syntax inventory, not a full parser conformance audit.
