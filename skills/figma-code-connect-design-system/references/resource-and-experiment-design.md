# Figma skill resources and change trials

Load this note through `mise run improvement-policy` before changing task order, cache use, data form, timing, experiments, or this skill.

## Product experiments

Run a large design test before a design layer is accepted. Freeze the user scene, state, text, view, orientation, input path, lower locks, claim, null, measure, falsifier, and rule before sight. Hold all unrelated facts still. The same sight owner views both choices and records the result. Fixed checks may veto a choice. They may not rank taste or grant visual PASS.

Lock a chosen lower owner before higher work. A new fact, failed access gate, code mismatch, missing state, or current visual fault may reopen it. Reopening a low owner marks each dependent Figma node, TypeScript React API, Code Connect map, render, and proof stale.

## Speed and resources

The speed goal is time to a fully proved integrated result. Run safe read checks at once. Change one Figma owner at a time. Start slow source, render, and readback work early. Use the first check that can reject a bad path. A quick partial result is not progress.

Cache only fixed work with full inputs, tool versions, environment, outputs, and invalidators. Never cache live Figma state, web state, model judgment, direct sight, approval, or a side effect. A cache hit proves saved work, not current product truth.

Use maps for node and property lookup. Use sets for coverage checks. Add proof to an ordered log. Stream large files once. Use content digests for invalidation. Replace one passed owner as one safe write. Add a harder data form only after a timed block shows a real gain.

## Optional skill change

After required product work passes, run `mise run improvement-policy`. Freeze the last passed digest, evaluator, inputs, environment, time cap, repeats, and resource checks. Change one named part at its smallest owner. Keep it only if that part gets better and no protected part gets worse. If any part gets worse, restore the last passed version and rerun its proof.
