# Creative transfer

Read this file in Step 08 after current and distant sources pass `assets/creative-source-frontier.json`. It owns the move from an outside mechanism to a testable token decision. Use `mise run token-packet -- <args>` for this routed resource.

## Transfer record

Record the source ID, domain, target decision, token paths, preserved relational structure, forbidden surface traits, prediction, baseline, matched alternative, falsifier, stop rule, proof regions, and disposition.

## Relational structure

State the connected cause, sequence, topology, feedback, constraint, or role relation that can transfer. A shared topic, look, color, motif, material, or mood is not enough.

## Forbidden surface

List source traits that must not be copied. Include motifs, layout skeletons, ornamental details, named styles, wording, and distinctive assets when present.

## Test

Render the baseline and matched transfer while holding unrelated variables fixed. Reject the transfer if the predicted visual, behavioral, perceptual, or physical effect does not appear, if a simpler source-local explanation fits better, or if the result depends on a copied surface trait.

## Save and route

Save one transfer record per decision in `exploration.ledger`. Feed retained transfers to Step 09, rejected transfers to the negative-pattern record, and blocked transfers to `E_TRANSFER` with the missing evidence.
