# Rubric

Score each criterion as `PASS` or `BLOCKED`. A case passes only when every applicable criterion passes and no veto occurs.

1. **Routing:** The skill activates for DTCG generation, validation, or proof and rejects nearby output tasks.
2. **Inventory:** Every source has identifier, locator, kind, format facets, intent facets, and SHA-256.
3. **Vision:** Every visual source has whole-frame, detail, and comparative native-vision passes with located observations.
4. **Vision gate:** The active model has strong native vision or every judgment task is delegated to a strong vision-capable model; otherwise `E_VISION` blocks token and proof output.
5. **Evidence boundary:** Observed, inferred, and assumed statements remain distinct.
6. **Identity:** The thesis names audience, context, feeling, and a source-specific idea and fails noun substitution.
7. **Universe:** Every token possibility starts in the ledger and receives one disposition before narrowing.
8. **Context:** Every material source and intent requirement maps to token paths or an explicit omission.
9. **Permutations:** Applicable type, role, state, mode, component, context, value, viewport, motion, and input branches are accounted for.
10. **DTCG:** Names, types, values, references, and cycles pass the bundled 2025.10 validator.
11. **Architecture:** Primitives, semantic roles, and supported component roles use aliases instead of duplicated literals.
12. **Specificity:** At least five signature decisions across three axes cite source evidence and token paths.
13. **Artifact authorship:** The HTML structure, content, copy, specimens, and styling are authored for this run, not filled into a reusable visual shell.
14. **Objective defects:** Every visual defect marker is reviewed; zero vetoes and zero major defects remain unresolved.
15. **Invariants:** Every perceptual-motor invariant is accounted for with token feasibility and rendered evidence where used.
16. **Taste:** Fitness, hierarchy, rhythm, voice, restraint, detail, and state coherence pass reasoned visual review with counterevidence.
17. **Originality and uniqueness:** Source lineage, falsification tests, and a frozen declared-corpus comparison pass without a global claim.
18. **Non-AI-slop:** Reasoning aligns with implementation; filler, generic shells, unsupported ornament, repetition, fake data, and unresolved details are absent.
19. **Proof integrity:** Final wide and narrow readback, embedded data, hashes, visible status, failures, and limits agree.
20. **Recovery:** Failed gates cause source, token, evidence, or artifact repair, never verdict-only editing.

The judge cites visible output or supplied trace for every pass. An unsupported assumption is `BLOCKED`.
