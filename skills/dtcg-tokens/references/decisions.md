# Decision log for dtcg-tokens

One dated line per decision, newest first. Record the choice, reason, and evidence.

- 2026-08-27: Required two experimental tokens from two distinct enumerated strategies, with exact token, ledger, evidence, specimen, and final-review path equality, so exploration cannot disappear during narrowing or presentation.
- 2026-08-27: Removed the reusable proof renderer and all positive visual fixtures because artifact styling and content must be authored from the current sources and tokens, then reviewed with strong native vision.
- 2026-08-27: Split objective defects, perceptual-motor invariants, taste, originality, corpus uniqueness, and non-AI-slop into separate catalogs and verdict tracks because one blended score can hide a disqualifying failure.
- 2026-08-27: Made native visual reasoning a blocking requirement for every visual source because source identity, composition, hierarchy, and material cues cannot be proved by metadata or OCR.
- 2026-08-27: Added an all-or-nothing vision execution gate so every judgment moves to a strong vision-capable model when the active model cannot inspect the sources directly.
- 2026-08-27: Added a fixed stage machine, task re-anchoring, atomic evidence, counterchecks, stable error codes, and a completion matrix to make long mixed-input runs repeatable and auditable.
- 2026-08-27: Limited originality claims to a named comparison corpus because global uniqueness cannot be established without exhaustive comparison.
- 2026-08-27: Pinned DTCG 2025.10 and bundled the official schema because it is the current stable format baseline.
- 2026-08-27: Made the HTML report self-contained and data-driven so reviewers can inspect tokens, evidence, hashes, limits, and quality gates without a network dependency.
