# Taste, originality, uniqueness, and non-AI-slop

Use `assets/judgment-review-catalog.json` as the canonical obligation list, `references/qualitative-judgment.md` for subjective and emergent lenses, and `references/visual-review.md` for the execution method. Keep the four verdicts separate. Use `mise run token-packet -- <args>` for this routed resource.

## Taste

Taste is reasoned visual judgment, not a claim of mathematical certainty. Review fitness for audience and task, reading order, rhythm, typographic voice, color relations, earned expression, restraint, detail finish, memorability, and coherence across states.

A pass requires located visual evidence, comparison with a credible alternative, and the strongest counterevidence. Personal preference, fashion, novelty, symmetry, asymmetry, minimalism, or maximalism cannot fail taste alone.

## Originality

Originality requires at least five source-derived signature decisions across at least three applicable axes. Each decision links source evidence, affected token paths, rendered regions, audience fit, and the generic default it replaces.

Run these falsification checks:

- **Noun substitution:** replace product, audience, and brand nouns with two unrelated domains. The identity and rendered system should become visibly false.
- **Transplant:** map an unrelated brief into the same layout, content grammar, and visual system. Material structure should break.
- **Surface removal:** remove color, font, identifying copy, and ornament. Source-specific hierarchy and anatomy should remain.
- **Claim alignment:** map every design rationale to implemented regions and tokens, then map implementation back to rationale.
- **Lineage reversal:** reconstruct a decision from rendered region to token to decision to observation to source.

A novel flourish cannot substitute for an original system. Signature decisions must interact across axes.

Treat category familiarity and source-specific difference as joint tests. Compare the token system with a relevant category default, then identify which familiar values remain and which relationships make the result product-specific. Do not reward rarity by itself. A distinctive relation must improve meaning, priority, recognition, or interaction while familiar control behavior and applicable standards remain intact.

## Corpus-bounded uniqueness

Freeze a named, nonempty, relevant comparison corpus and every threshold before computing results. Compare exact hashes, normalized token graphs, semantic graphs, layout skeletons, content grammar, specimens, full-color appearance, grayscale appearance, edge structure, hierarchy, and nearest neighbors.

The artifact passes only within that declared corpus. Color-only or metadata-only distance cannot establish uniqueness. Keep `globally_unique` false and state: `Global uniqueness is outside this skill's valid claim scope and remains unproved.`

## Non-AI-slop

Review observable output traits, not presumed authorship. Check reasoning-to-implementation gaps, missed source clauses, generic shells, filler, unsupported ornament, microdetail inconsistency, purposeless repetition, speculative scale completion, fake examples, compound-constraint loss, and unsupported attribution.

Appearance and detector scores do not prove who or what created an artifact. Authorship claims require provenance. A non-AI-slop pass means the output lacks the cataloged failure traits within the reviewed scope.

## Creative boundary

Originality does not require novelty for its own sake. Perceptual and motor invariants protect minimum human outcomes, not familiar form. Experimental token branches, new token extensions, unfamiliar composition, and rule-breaking remain valid when actual rendered use preserves or replaces the protected outcome with equally effective access.
