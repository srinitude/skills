# Evaluation contract

## Scope

Evaluate activation, rejection, classification behavior, failure handling, recovery, and speed under both `with_skill` and `without_skill` conditions. Run each case twice. Keep activation, behavior, source-preservation, and whole-package results separate.

## Activation

Activate when instructions materially mix an observable result, proof, boundary, or forbidden state with a possible implementation route. Reject simple requests with no material method choice, exact-copy requests with no classification task, and ordinary inspection requests that do not ask for contract separation.

## Behavior

A passing response loads `starting-point` before classification, keeps outcome and proof separate from candidate paths, preserves exact and explicit methods at their original strength, keeps safety and privacy rules fixed, shows one inspectable contract early, and asks at most one question when unresolved classification would materially change the work.

Artifact audit mode reads the complete source, assigns stable source IDs, returns a classification ledger and minimally changed proposed contract, and never mutates the source without separate authorization. Conversation mode updates one provisional contract instead of restarting discovery.

## Failure and recovery

When required source text is unavailable, stop the audit and report the missing source rather than inventing clauses. When a requirement-versus-recipe distinction stays unresolved, mark it unresolved and ask one concise question. When an alternative would drop, delay, or reprioritize accepted work, keep the current route until the user approves the change.

Recovery reuses the accepted contract, restores any omitted invariant or veto from source evidence, and reruns the affected case. A classification ledger, rewrite, or contract is not execution proof.

## Model disclosure

A judge may assess only the supplied prompt, response, trace, native requirements, and vetoes. It must not infer hidden source reads, approvals, mutations, or external actions. Missing direct evidence remains unproven.

## Decision rule

Every native required item must pass and every native veto must remain absent. One demoted mandatory method, lost boundary, invented requirement, unauthorized scope reduction, source mutation, or unnecessary contract interview makes the case `BLOCKED`.
