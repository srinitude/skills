# Evaluation contract

## Scope

Evaluate activation, rejection, ordered strategy behavior, failure handling, and speed under both `with_skill` and `without_skill` conditions. Run every case twice. Keep historical source preservation, authorized loss, video-learning coverage, companion-skill coverage, behavior, and whole-package results separate.

## Activation

Activate for hard, high-stakes, or ambiguous work that needs strategy, adversarial review, stakeholder behavior reasoning, workflow redesign, or a bounded path to repeatable execution. Reject simple facts, mechanical edits, direct calculations, ordinary summaries, and exact-copy requests unless the user asks for strategic treatment.

## Behavior

A passing response applies `starting-point`, `always-current-date`, and `outcome-bounded-work` in that order, then runs `FRAME -> DRAFT -> CHALLENGE -> TEST -> DECIDE`. It selects one measurable high-value outcome, uses CRIT without a long questionnaire, produces a concrete draft, challenges its weakest assumption, preserves user judgment, and turns behavior claims into reversible tests. A missing named companion uses the stated local fallback instead of blocking the whole method.

Supplemental cases require unpolished context intake, deliberate practice, cognitive independence checks, first-principles redesign, clear outcome ownership, bounded advisory perspectives, approved-sample voice calibration, least-data design, outcome-labeled feedback, and rejection of personality diagnosis or manipulation.

## Failure and recovery

When the current-time anchor is unavailable, use `temporal-anchor-unavailable` and stop only date-dependent work. When one unretrievable answer would change the route, enter `QUESTION` and ask only that question. Keep simple requests outside the state machine.

## Claim limits

A judge may assess only the prompt, visible response, supplied trace, required behaviors, and vetoes. It must not infer hidden tool calls, approvals, writes, or real stakeholder behavior. Anecdotes, promotions, forecasts, and capability timelines remain claims unless the case provides evidence.

## Decision rule

Every required item must pass and every veto must remain absent. An out-of-order companion binding, skipped state, lost boundary, invented fact, personality inference, unsupported behavior claim, or replacement of user judgment makes the case `BLOCKED`.
