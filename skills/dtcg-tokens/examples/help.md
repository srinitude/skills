> What can dtcg-tokens do?

## Visible reply

`dtcg-tokens` accepts `help`, `generate <inputs>`, `validate <tokens>`, and `prove <tokens> <evidence>`. Generation accepts text, documents, data, code, images, screenshots, video, audio, live interfaces, and mixed sources. It creates DTCG 2025.10 JSON, evidence JSON, a run-specific standalone HTML proof, and a run record. Every final token file contains at least two experimental tokens from two different exploration strategies. Visual input and proof artifacts require native visual inspection. Originality is provable only inside a named comparison corpus; global uniqueness cannot be proved without an exhaustive corpus.
