# Exploration synthesis

Read this file in Step 08 after the source identity graph, screen ledger, and current research record exist. It owns the run-local corpus and candidate order defined by `assets/exploration-corpus/manifest.json` and `assets/exploration-corpus/synthesis-contract.json`. Use `mise run token-packet -- <args>` for this routed resource.

## Load typed material

Load the manifest and only the shards needed by the run. A primitive is a controllable atom. An operator changes an atom or relation. A mechanism predicts cause and effect. A concept arranges them for a purpose. A theme is a source-backed proposition. A tension holds opposing forces. A constraint sets a boundary. A question can change a decision. An idea is a run-specific testable hypothesis.

## Build the run-local corpus

Join source graph relations, user intent, applicable screen tuples, distant mechanisms, active themes and antitheses, current technology records, rejected precedents, unanswered questions, and uncertainty. Each entry keeps its source or instruction location.

## Generate before judging

Derive the saved seed from input hash, intent hash, corpus version, and run ID. Freeze at least twelve candidates before taste filtering: three combinational, three exploratory, three transformational, and three antithetical. Add more when a modality or underused corpus cell needs coverage.

## Complete each candidate

Record at least two source relations, a primitive, operator, mechanism, theme or tension, constraint, question, predicted effect, falsifier, screen tuple, maturity, and exact token paths. Include physical interaction when applicable. Reject only impossible tuples, invalid records, duplicates, forbidden outcomes, or missing source relations during generation.

## Evaluate

Apply lineage and hard vetoes first. Render matched alternatives. Run ablations and counterfactuals. Use strong vision for located comparison. Judge originality, identifiability, corpus uniqueness, source fit, taste, and non-slop as separate tracks. Retain a set of distinct passing mechanisms instead of one blended score.

## Block

Return `E_CORPUS` for a missing shard, stale manifest, invalid entry, missing run-local extension, fewer than twelve candidates, absent lane, duplicate variety, early taste filtering, or retained token without complete lineage.
