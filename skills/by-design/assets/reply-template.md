# Reply template

Fill every line. Delete no line. When a line has nothing to report, write none.

```
Posture: <judge, choose, shape, audit, watch, or ask>
Ledger: <path>, <n> rows added, <n> marked inherited
Found: <one sentence naming the decisions, not the questions>
<one question, or the word none>
```

The first line names the posture, so a reader knows what kind of answer this is. The second line carries counts that came from a command in this turn. The third line reports decisions. The fourth line holds one question at most, and the word none is a complete and common answer.

For the ask posture, replace the fourth line with the slice itself and pass `--full-slice` to the reply check.
