# Practice loop

Load this only when the user wants to build strategic use as a habit. It is optional for ordinary task execution.

## Thirty-day routine

1. Place one visible cue where work begins: "What is the highest-value problem here?"
2. Choose one real problem per day. Do not manufacture work to satisfy the routine.
3. Write an unaided baseline: the goal, current belief, strongest reason, and greatest uncertainty.
4. Add rough context with CRIT. Dictation or unedited notes are acceptable.
5. Ask for one challenged strategy and one disconfirming test.
6. Compare the result with the unaided baseline. Record what changed and why.
7. Take one reversible action or explicitly decide that no action is justified.
8. Record the observed result, not a confidence score.

## Weekly review

- Which problems produced a measurable gain?
- Which questions exposed a false assumption?
- Where did assistance weaken independent reasoning or authorship?
- Which repeated process is now understood well enough to document?
- Which use should stop because value, evidence, permission, or safety is missing?

## Limits

Do not use the routine to monitor people, pressure daily compliance, collect private material, or reward volume. The purpose is better judgment and action, not more interaction.
