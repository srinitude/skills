# Markdown candidate inventory

- Read this whole inventory before choosing forms for a passage or a group with the same purpose and target.

## Read before choosing

- Prerequisites: the reader, passage purpose, target format, and the rules already loaded for this invocation.

### Candidate coverage

- Consider each of these 136 named entries. Record use, rule out, or unresolved, with a reason for each.
- A shared reason may cover named entries. Keep an unknown form unresolved until its owner and meaning are known.
- These links lead to detailed How, When, Where, Why, syntax, and source guidance. Read a detail page when needed to decide.
- The groups below are peers. Their position does not create prerequisites. Detail pages require no return read.
- C means CommonMark form; G means formal GFM extension; E means listed extension; A means listed host or embedded form.
- A dialect is a syntax rule set. GFM means GitHub Flavored Markdown. MDX adds JSX and JavaScript to Markdown.
- MMD6 and MMD7 mean MultiMarkdown versions 6 and 7. MyST, Quarto, Markdoc, and other named systems have their own rules.
- This is a complete inventory of this catalog, not every extension ever made. Consider unfamiliar input forms too.
