# Judgement gates

Resource gate: run `mise run validate` before using package files named here.

Backlink: [SKILL.md](../SKILL.md). Load for candidate selection and release.

Use the same frozen bytes for every validator. Record validator name, revision, status, inputs SHA-256, findings, vetoes, and verdict SHA-256.

## External order

1. Impeccable
2. TasteSkill
3. every applicable Emil procedure
4. native invariant review

Unavailable validators do not inherit a pass. Record the unavailability class and run the native fallback.

## Native wireframe gate

Block on:

- a missing conversion or section obligation
- style leakage
- weak or competing primary actions
- unsupported claim or proof placement
- broken semantic or focus order
- missing breakpoint adaptation

## Native identity gate

Block on:

- generic visual choices without audience reason
- illegible type, weak contrast, or uncontrolled density
- inconsistent system behavior
- image treatment that conflicts with the message
- identity that changes frozen structure

## Native craft gate

Review alignment, spacing rhythm, optical balance, edge cases, responsive crop, content overflow, empty states, controls, hover, focus, active, loading, error, and reduced motion. Check real copy and real assets, not placeholders.

## Native taste gate

Ask whether every visible choice is intentional, specific to the product and audience, and necessary for comprehension or persuasion. Remove decoration that has no job. Reject cloned reference appearance, ornamental noise, arbitrary gradient use, and interchangeable hero composition.

## Verdict

Any factual, accessibility, structure, capability-floor, or severe performance veto blocks. Other findings permit at most two bounded repair passes. A repair invalidates its stage and all dependent evidence. Pass only when all available validators and native gates have no veto.
